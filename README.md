# Douane Temporelle

Mini-projet (DS 1) - Programmation Mobile - 3ème BI - FSEGT
Enseignant : Nidhal Jelassi

## Membres du groupe
- Lina TABOUBI
- Wissal Boulaaress
- Yassine Cherif

## Description
Application Android simulant un poste de douane pour voyageurs du temps.
Elle contient 3 activités :
- MainActivity : formulaire d'enregistrement du voyageur
- VerificationActivity : scanner de paradoxe (passeport)
- ResultActivity : verdict final (approuvé ou refusé)

## Informations techniques
- Langage : Java
- Matricule utilisé pour les clés putExtra : 9886
- Initiales utilisées dans les IDs : wb
